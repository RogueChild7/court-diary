Court Diary Privacy Policy

Last updated: 20 November 2026

Who we are

Court Diary is a desktop application used privately by one advocate to manage court dates and deadlines. Questions about this policy can be sent to muigai.imn@gmail.com.

Where your information is kept

Matters, court dates, notes and documents entered in Court Diary are stored on the user's own computer. They are not sent to any server operated by Court Diary.

Google user data

Connecting a Google account is optional. If the user connects one, Court Diary asks for two limited permissions:

  • Google Calendar (calendars created by the app only): Court Diary creates a calendar named "Court Diary" and adds, updates and removes events in that calendar only. It cannot see or change the user's other calendars. Event entries carry a case number, stage and court station so that Google can send reminders.
  • Google Drive (app data folder only): Court Diary can store an encrypted backup file in its own hidden application folder in the user's Google Drive. It cannot see or change any other files in Drive.

Google user data obtained through these permissions is used only to provide these features to the user. It is not sold, not shared with third parties, not used for advertising, and not used to train any artificial intelligence model. Court Diary's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

Sign-in tokens issued by Google are stored on the user's computer. Backups are encrypted with a password chosen by the user before they leave the computer.

Removing access and deleting data

The user can disconnect Google at any time from Court Diary's settings, or remove Court Diary's access at myaccount.google.com/permissions. The "Court Diary" calendar and the backup file can be deleted from Google Calendar and Google Drive at any time. Deleting the app's data folder on the computer removes all local records.

Changes

Any change to this policy will be posted on this page with a new date.
